# Decision Core Package

This directory contains the documentation companions for the decision-assurance
package located in:

- `models/decision-core`

Start with:

- `decision-core-evidence.md`
- `decision-core-namespace.md`
- `standards-alignment.md`

why the package exists, how the lineage was reconstructed, how the namespace is
being stabilized, and how the validation gate is expected to behave.
